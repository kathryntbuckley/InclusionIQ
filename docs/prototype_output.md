# InclusionIQ Prototype Output Example

This file shows an example of the output generated by `src/analysis_prototype.py` when run against the fictional sample dataset in `sample_data/employee_feedback_sample.csv`.

```text
# InclusionIQ Prototype Analysis

Responses analyzed: 15
Overall sentiment: Mixed-positive

## Average Scores
- Respect Score: 3.67/5
- Communication Score: 3.53/5
- Fairness Score: 3.27/5
- Belonging Score: 3.67/5

## Top Themes
- Psychological Safety: 9 keyword matches
- Leadership Communication: 8 keyword matches
- Advancement and Development: 6 keyword matches
- Team Support: 6 keyword matches
- Fairness: 4 keyword matches

## Recommended Actions
- Create a consistent communication process for policy, scheduling, and role expectation updates.
- Clarify promotion criteria, development pathways, and internal mobility options.
- Encourage managers to invite input and respond constructively to employee concerns.
- Recognize and reinforce supportive team behaviors already working well.
- Review how opportunities are communicated and distributed across teams.

## Ethical Note
This prototype uses fictional, anonymized sample data and is designed to support organizational improvement, not evaluate individual employees.
```

## What This Demonstrates

The prototype connects the full InclusionIQ workflow:

1. **Input:** Fictional employee survey responses
2. **Analysis:** Average score calculation and keyword-based theme detection
3. **Output:** A readable workplace insight summary with recommended actions

This early output is intentionally simple. Future versions can expand the analysis with stronger natural language processing, dashboard visualizations, and AI-assisted report generation.
